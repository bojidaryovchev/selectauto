# Rules:

- never guess, hypothesize, invent or act without thoroughly researching and backing up your claims with evidence
- never implement an external library without checking its latest docs online, always expand all sections recursively to read everything
- never be lazy when reading files, always read them in their entirety
- never do anything or answer a question before properly reasoning about everything you currently know and asking yourself the very basic questions, think out-of-the-box

# UI work

For anything a user or admin sees in `apps/web`, read [docs/design/README.md](docs/design/README.md) first, and build each screen with the `selectauto-design` skill (`.claude/skills/selectauto-design/SKILL.md`). Its first step checks the screen's boards against today's code, so nothing the product does is lost.
