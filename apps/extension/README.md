# SelectAuto Lot Checker (browser extension)

A read-only companion extension for SelectAuto sales agents. On a **Copart**,
**IAAI** (US/CA) or **Encar** lot page it detects the lot, asks selectauto.bg
whether that exact lot is already a listing, and shows a floating panel with:

- **✔ Вече е в базата** (active) — with a one-click **Viber message** + a deep
  link to the `/avtomobil/{id}` page.
- **🏁 Продаден** (past/sold) — link to the auction-result page.
- **ℹ️ В базата (не е листната)** / **🔍 Не е в базата** — informational.

It is **read-only**: the only network call is a `GET /api/lot-check` to
selectauto.bg. It does not scrape the auction sites or write anything. This is a
deliberate rewrite of the legacy `selectauto_checker/` extension, whose ~3,000-
line scrape-and-import engine became redundant once all three sources are
ingested automatically from AuctionsAPI.

## How it maps to the backend

`detectCarPage()` extracts the on-page lot id, which equals
`auction_lots.lot_number` in Neon (Copart lot #, IAAI stock #, Encar car-id —
verified against live data). The endpoint resolves that to a `car_id` and reads
the same `car_listings` / `car_listings_archived` projections the catalog uses,
so the panel shows byte-identical title/price/mileage. See
`apps/web/src/app/api/lot-check/route.ts`.

## Develop

```bash
pnpm --filter @selectauto/extension dev        # Chrome, HMR
pnpm --filter @selectauto/extension dev:firefox
```

In dev the extension calls `http://localhost:3000` — run `pnpm dev:web`
alongside. `wxt dev` launches a browser with the extension loaded; open a real
Copart/IAAI/Encar lot page to see the panel.

## Build / package

```bash
pnpm --filter @selectauto/extension build   # -> .output/chrome-mv3
pnpm --filter @selectauto/extension zip     # -> .output/*.zip
```

Load unpacked from `.output/chrome-mv3` via `chrome://extensions` (Developer
mode) for manual testing of a production-pointed build.

## Stack

[WXT](https://wxt.dev) + TypeScript. Entrypoints in `entrypoints/`
(`background.ts`, `content.ts`), shared code in `lib/`, icons in `public/icons/`.
The Manifest V3 manifest is generated by WXT from `wxt.config.ts`.
